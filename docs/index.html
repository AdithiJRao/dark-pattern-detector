Install in a minute

Works in Edge, Chrome and Brave. You load it once, and it stays installed.

  1. Download and extract. Click Download extension above, open the zip, click Extract all, and save the folder somewhere permanent, such as Documents. Deleting the folder later removes the extension.
  2. Open the extensions page. In Edge, type edge://extensions in the address bar. In Chrome or Brave, type chrome://extensions. Then turn on Developer mode.
  3. Click Load unpacked and select the extracted folder, the one containing manifest.json.
  4. Open any shopping site. Flagged text gets a red outline, and the extension icon shows how many.

Nothing to run and no sign-up. It works offline.

What it catches, and what it doesn’t

It is a text classifier, so it judges wording only.

Flags

  • Scarcity: “Only 3 left”, “Almost gone”
  • Urgency: “Hurry”, “Offer ends in 10 minutes”
  • Social proof: “20 people are viewing this”

Does not catch (yet)

  • Hidden fees added at checkout
  • Pre-ticked boxes and trick buttons
  • Anything that is not text on the page

It can also flag harmless text by mistake. Treat a red outline as “look twice,” not proof.

Help improve it

The model learned from about 3,000 English phrases, so it will miss some wording and flag some harmless text. If you spot either, tell me. Reports are reviewed by hand before they are used to retrain the model.

Data and how it works

A TF-IDF and logistic regression model trained on about 3,000 labeled shopping phrases, exported to run directly in the browser.

The extension doesn’t highlight anything

Open edge://extensions or chrome://extensions, make sure the extension is on and Site access is “On all sites,” then refresh the shopping page. Some pages load text late, so wait a couple of seconds.

Is my browsing data sent anywhere?

No. The extension runs the model inside your browser, and page text never leaves your computer. The only thing this website collects is text you choose to type into the report form above.
